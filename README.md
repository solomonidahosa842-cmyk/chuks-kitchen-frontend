Chuks Kitchen Frontend Assignment

Project Overview

Chuks Kitchen is a responsive food ordering web interface built as part of a frontend internship assessment.  

The goal of this project was to translate Figma UI designs into clean, structured, and responsive web pages using core frontend technologies only (no backend or APIs).


Tech Stack

- HTML5 (Semantic structure)
- CSS3 (Flexbox & Grid)
- Mobile-first responsive design

No backend, API integration, or authentication was implemented, as instructed.

Pages Included

All pages are connected using proper relative linking:
- Home
- Explore/Food
- My Orders
- Account/Sign up
- Payment

Features
- Fully responsive layout (mobile & desktop)
- Semantic HTML structure
- Flexbox & CSS Grid layout systems
- Clean folder organization
- Consistent color system and typography

💡 Lessons Learned
During this project,  I strengthened my understanding of:
Relative Pathing: Mastered directory navigation (../) to ensure images load correctly across different folder structures.
Responsive Backgrounds: Learned to use background-size: cover and background-position: center to prevent image distortion on window resizing.
Layout Stability: Solved "overflow" issues by replacing rigid pixel-based margins with flexible Flexbox alignments.

 Limitations

- Buttons and forms are UI-only (non-functional), except for the continue button in signup.html that leads to the home.html.
- No data persistence or authentication system was implemented.
- No external APIs were used.

How to Run the Project

1. Download the project folder.
2. Open `Signup.html` in a browser.
3. Navigate between pages using the navigation links that can be found at the footer or just click on the continue button.
